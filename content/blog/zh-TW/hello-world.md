**TL;DR：** 我想開一個分享作品與學習心得的地方——工程筆記、實用指南，還有對 side project 老老實實的覆盤。這個網站本身是一個全靜態的 Next.js 建置，每月成本 $0，同時針對 Google 和 AI 搜尋引擎做了最佳化。

嗨，我是 Oliver。這是我在網路上的一小塊自留地。

過去一段時間，我的筆記散落在各個地方：一個 app 裡躺著寫到一半的草稿，另一個 app 裡存著程式碼片段，還有那些值得一分享的想法，全被塞進 280 個字元裡。這個部落格就是為了收拾這個殘局——把東西好好地寫下來、公開寫出來，寫在別人真的用得上的地方。

## 預期內容

我是軟體工程師，大部分時間都泡在 TypeScript 和瀏覽器裡，所以寫的東西大概也是這些：

- **建置日誌** —— side project 實際上是怎麼做出來的，包括無聊的部分和犯過的錯。
- **實用指南** —— 例如怎麼上線一個排名表現好的靜態網站，或者怎麼在不抓狂的前提下接上結構化資料。
- **軟性觀點** —— 關於開發者工具、網頁效能，以及為什麼部落格長得都一模一樣。

## 為什麼這個網站是現在這個樣子

幾個原則塑造了這次建置：

1. **沒有伺服器，就沒有帳單。** 每一頁都是預先渲染好的 HTML，放在免費的 CDN 上。全球載入都很快，而且運行成本是零。
2. **人和機器都找得到。** 乾淨的 URL、RSS、sitemap、結構化資料，還有一份純 Markdown 的 `llms.txt`，讓 AI 助理也能讀懂這個網站。
3. **寫在檔案裡，而不是表單裡。** 文章是 git repo 裡的 Markdown 檔案。這代表有版本歷史、可以離線寫作，而且不會被任何平台綁架。
